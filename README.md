# Markdown学習用Webエディタ

本ソフトウェアは、Markdownの学習・演習を目的とするWebエディタです。

「かんたんmdくん」（原作者：phys_ken）をもとにした教材用の改変版です。

- 原作名：かんたんmdくん
- 原作リポジトリ：[phys-ken/2024informatics_ic](https://github.com/phys-ken/2024informatics_ic)
- 原作エディタ：[Markdown editor](https://phys-ken.github.io/2024informatics_ic/tools/markdown_edit/)
- 原作ライセンス：GNU General Public License v3（GNU GPL v3）

本改変版もGNU GPL v3の条件に従います。ライセンス全文は [LICENSE](LICENSE) を参照してください。

原作の帰属情報、改変履歴、外部ライブラリのライセンス情報は [NOTICE.md](NOTICE.md) に記載しています。

現在の改変版バージョン：1.3.0

Markdown入力欄の内容を全文コピー、全文クリアできます。

画面ヘッダーの`#app-version`に表示バージョンを管理しています。バージョン更新時は、ヘッダー表示とこの記載を合わせて更新してください。
